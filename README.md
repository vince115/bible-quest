# Bible Quest — 經文卡牌冒險

以聖經故事為題材的卡牌對戰玩法原型。

> 目前仍是測試中的原型，內容與規則隨時會調整。

## 執行

需要 Node.js 20.9 以上和 [pnpm](https://pnpm.io)。

```bash
pnpm install
pnpm dev
```

開啟 <http://localhost:3000>。

## 技術

Next.js · React · TypeScript · Tailwind CSS · Zustand
