# Rarity (C / R / SR / SSR / UR)

Rarity expresses **collection value and significance**, not power:
- How hard the card/character is to obtain.
- Effect complexity and tactical uniqueness.
- Importance of the Bible event or Scripture.
- How special the character version is.
- Evolution potential (a separate concept from rarity).

## Avoid
- Higher rarity = more damage/heal/HP. That creates power creep and makes common cards pointless.
- Filling a small prototype with SSR/UR. Keep the distribution low; leave the top tiers for truly
  significant Scripture and character versions.

## Healthy patterns
- Higher rarity changes **shape**: a new condition, a synergy, a tactical option, a story-specific twist.
- Common cards stay useful as the backbone of every hand.
- Character versions (e.g. David as shepherd, as giant-slayer, as king) differ by skills and identity,
  each balanced for its role.
- Evolution changes the effect's form (new synergy, condition or utility), not just bigger numbers.

## Bible Quest status
Rarity is a data-model topic only. No gacha, packs, shop, evolution, collection or upgrade UI unless the
user asks. Rarity must never be read by combat rules.
