# RNG design

Principle: **randomness should create decisions, not cancel them.**

| Source | Before or after the decision? | Effect on agency |
|---|---|---|
| Card draw | Before | Good — new options to evaluate |
| Enemy intent (telegraphed) | Before | Good — a threat to plan around |
| Random target (telegraphed) | Before | Good if shown in the intent |
| Random target (hidden, at resolution) | After | Weak — feels arbitrary |
| Damage ranges | After | Mild loss; acceptable if narrow |
| Hit/miss, crit | After | Strong loss — a correct play can fail |
| Random effects | After | Fun in moderation; hard to read |

## Mitigation tools
Telegraphs, deck knowledge (counts of deck/discard), card selection (choose 1 of N), guaranteed outcomes
for committed payoffs (the climax should never miss).

## Does Bible Quest need dice?
**Not now.** The prototype already has input randomness (draw order, Goliath's single target). Dice would
add output randomness to a 3–5 turn encounter, where one bad roll is a large share of the game, and they
would undercut the theme of trusting God rather than luck in 1 Samuel 17. Revisit only if playtests show
turns are too predictable *and* the randomness can be placed before decisions (e.g. a revealed roll
that sets this turn's option, not a hit/miss after committing). Don't add dice without the user asking.
